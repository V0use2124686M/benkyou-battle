# べんきょうバトル

小学2〜4年生向けの学習ゲーム(英語モードは入門レベル、れきしモードは小6の学習内容)。
問題に正解してモンスターを攻撃するバトル形式。
ゲーム本体は `index.html` 1ファイル(HTML+CSS+JS)に収まっており、ビルドも通信も不要。
外部ファイルはモンスター画像 `monster01〜15.webp` だけで、無ければ絵文字にフォールバックするため
`index.html` 単体でも遊べる。

## モード
- **かけ算モード**: 九九からランダム出題。レベル7以降は2桁×1桁も混ざり、レベル9以降はさらに範囲が広がる
- **わり算モード**: 答えが整数になる割り算。レベル7以降は2桁÷1桁(答えも2桁、割られる数は99まで)も混ざる
- **かんじモード**: 配当漢字216問(1〜3文字の熟語を含む)を4択で出題。「漢字→読み」と「読み→漢字」の2形式が半々で出る。レベル1〜6は小2中心、7〜8は小3中心、9以降は小3+小4。送り仮名のある言葉(泣く・選ぶ等)は選択肢も送り仮名ありの言葉だけになる
- **ちりモード**: 6種類の問題がランダムに混ざって出題される。問題文・選択肢の漢字にはふりがな(ルビ)が付く
  - 都道府県⇔県庁所在地(25%): レベル1〜6はよく知られた16都道府県、7〜8は中堅16県、9以降は残り15県を加えた31県から出題。県庁所在地を答える問題では「滋賀県→滋賀市」「埼玉県→埼玉市」のような**県名+市のひっかけ**が1つ混ざる(県庁所在地が県名と違う17県のみ。栃木市・山梨市・沖縄市のように実在するが県庁所在地ではない市も含む)
  - 何地方の都道府県か(15%): 8地方区分(北海道・東北・関東・中部・近畿・中国・四国・九州)から選ぶ
  - 地図記号(15%): 学校・郵便局・神社・寺・病院など16種類をSVG/絵文字アイコンで出題。国土地理院の記号の由来(例: 田=稲を刈った跡、畑=植物の二葉、病院=十字、警察署=交番の記号を丸で囲む)にもとづいた簡略デザイン。レベルに応じて記号の難度も上がる
  - 世界の国当て(15%): ヒントの文章から国名を当てる。有名な30か国を出題
  - 日本一・日本三大(15%): 長い川・流域面積・高い山・大きい湖・深い湖・広い平野・都道府県の面積と人口のランキング、東西南北のはしの島、日本三景・三名園・三名瀑。レベル1〜8は「いちばん」、9以降は「2ばんめ・3ばんめ」を問う。三景・三名園・三名瀑はレベル7以降。答えが名前のときは「袋田の滝(茨城県)」のように場所を添えて1列で表示する。同じ高さで3位が2つある山(奥穂高岳・間ノ岳)は3位を問わない
  - 名産(15%): りんご・みかん・米・いちご・自動車など20品目の生産量1位の都道府県。統計の年度で1位が入れかわりうるもの(鶏卵・さつまいも・茶など)は入れていない
- **にほんしモード**: 小6〜中1のテストで問われるレベルの4択問題。人物70人・できごと65件(すべて年号つき)から4種類が混ざって出題される。人名・できごと・時代名の漢字にはふりがな(ルビ)が付く
  - ヒント→人物(30%): 「刀狩や検地をおこない…」などの説明から人物を当てる
  - できごと→年号(40%): 「徳川家康が江戸幕府をひらいた」→1603年。誤答は近い年から選ばれる(1600・1867など)ので年号の暗記練習になる
  - 年の範囲→時代(15%): 「1603年〜1867年」→江戸時代。開始・終了がはっきりしている8時代のみ使う
  - 時代の新旧(15%): 4つの時代から一番古い/新しいものを選ぶ
  - レベル1〜6は定番(604・645・708・1603・1868年など)、7〜8は大宝律令・遣唐使・承久の乱など、9以降は条約・憲法・戦後まで広がる
  - **答えが一つに決まる問題だけを出す方針**。できごとは「いつの時代?」ではなく「なん年?」で問う(テストでそう聞かれるため)。「その人は何時代の人か」は徳川家康のように安土桃山とも江戸とも取れるため出題しない。年号も説が分かれるもの(鎌倉幕府の成立=1185/1192)は入れず、「源頼朝が征夷大将軍になった」→1192年のように一意に決まる表現にしている。時代の範囲も、始まり・終わりが割れる平安/鎌倉/室町は使わない
  - 人物・できごとはシャッフルした山から1つずつ引くので、一巡するまで同じ問題は出ない
- **えいごモード**: 英単語44語を4択で出題。「英語→意味」と「意味→英語」の2形式が半々で出る。英単語にはカタカナのフリガナが付く(英語→意味の選択肢は、答えてから読みを表示する)。レベル1〜6は基本語(16語)、7〜8は中級(16語)、9以降は中級+上級(28語)

## 難易度とクリア
- レベル(=モンスターの番号)が上がるほど問題が難しくなる。3段階: レベル1〜6 / 7〜8 / 9以降
- かけ算・わり算はレベル9以降、約35%の確率で文章題が出る
- **レベル15のモンスターを倒すとゲームクリア**(クリア画面が出る)
- バトル中は「やめる」ボタンでいつでも中断でき、そこまでのスコアで結果画面になる

## 遊び方
- **ふだんは公開URLを開く**(スマホ・PCとも)。
- ローカルのファイルを直接ブラウザで開いてもよい(`index.html` をダブルクリック)。
- ローカルサーバーで確認したいときは `.claude/launch.json` に設定済み
  (`python -m http.server 8000`)。同じ Wi-Fi のスマホからは `http://<PCのIP>:8000` で開ける。

## モンスター画像
モンスターはレベルごとに1体ずつ全15体で、`monster01.webp` 〜 `monster15.webp` を表示する。
レベル10以降はボス級の新キャラで、ステータスも強化される(HP +60・攻撃力 +8)。
画像が無い場合は絵文字にフォールバックする。

差し替えるときは同名(`.webp`)で上書きする。PNGで受け取った場合は WebP に変換してから置く
(表示は横331pxなので**横720px・品質82程度**で十分。1枚あたり30〜110KB、全15枚で約0.9MB)。
変換にはPillowが使える: `im.convert("RGB").save("monsterNN.webp", "WEBP", quality=82, method=6)`

`picture/` にある `Level1〜9.png` は**初代のデザイン**で、現在表示している絵とは別物。
旧版の控えとして残してある(対応は `Level1〜8.png` = レベル1〜8、`Level9.png` = レベル11)。

## 記録
モードごとのハイスコアを localStorage に保存する(サーバーには何も送らない)。
保存先は **端末 × ブラウザ × URL(オリジン)ごと**に分かれるので、公開URLと `localhost:8000` の
スコアは別扱いになる。
タイトル画面の「スコアを リセット」ボタン(2回押して確定)で全モードのハイスコアを消せる。
